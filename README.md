# 芯位蜜线网课助手

适用于 [芯位蜜线](https://www.beeline-ai.com/) 的 Tampermonkey（篡改猴）脚本，将 **自动下一章节** 和 **后台计时兼容** 合并在一个文件中。

[安装合并版脚本](https://raw.githubusercontent.com/ThunderGodTG/beeline-course-helper/main/beeline-course-helper.user.js) · [查看脚本源码](./beeline-course-helper.user.js) · [更新记录](./CHANGELOG.md) · [问题反馈](https://github.com/ThunderGodTG/beeline-course-helper/issues)

## 功能

| 功能 | 行为 |
| --- | --- |
| 自动下一章节 | 识别视频结束弹窗中的“观看下一章节”，等待约 1 秒后点击。 |
| 防重复点击 | 同一次弹窗只点击一次；弹窗隐藏后再次出现时可重新触发。 |
| 后台计时兼容 | 为课程播放器原有的进度计时回调增加 Web Worker 计时来源，尝试缓解后台定时器限速带来的影响。 |
| 状态提示 | 左下角显示自动跳转状态，右下角显示后台计时状态。 |
| 暂停自动跳转 | 点击左下角状态按钮暂停，再次点击恢复；课程播放和网站自身的进度上报照常处理。 |

**后台兼容不等于进度已经保存。** 浏览器冻结整个页面、系统休眠、网络故障或登录失效时，脚本仍可能无法正常运行；课程完成情况以平台显示为准。

## 安装

1. 在 Chrome 或 Edge 中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击 [安装合并版脚本](https://raw.githubusercontent.com/ThunderGodTG/beeline-course-helper/main/beeline-course-helper.user.js)，在 Tampermonkey 页面确认安装。
3. 若已经安装“自动观看下一章节”或“后台计时兼容”两个旧脚本，先停用旧脚本，仅启用本合并版。
4. **刷新已经打开的课程播放页**，然后开始播放视频。

如果点击安装链接后只显示代码，可复制全部代码，在 Tampermonkey 中选择“添加新脚本”，替换默认内容并保存。

部分浏览器需要在扩展详情中开启“允许用户脚本”，或按浏览器版本启用开发者模式，详见 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)。

## 使用

正常打开课程并播放即可。视频结束弹窗出现后，脚本会等待约 1 秒，再点击下一章节按钮。页面在后台时，实际执行时间可能受到浏览器调度影响。

### 左下角：自动下一章

- **已运行，等待结束弹窗**：自动跳转功能已启动。
- **检测到结束弹窗，1 秒后切换**：已识别下一章按钮。
- **已点击，等待切换**：已发送点击操作。
- **已暂停，点击此处恢复**：点击状态按钮即可恢复自动跳转。
- **已点击，但弹窗仍显示**：点击后页面没有及时切换，可手动确认按钮是否正常工作。

### 右下角：后台计时

- **等待视频播放（安装后需刷新）**：尚未匹配到播放器的进度计时器。
- **已接管 1 个课程计时器**：已匹配计时回调并启动兼容计时。该提示不代表服务器已确认学习进度。
- **Worker 受限，已保留网站原计时**：浏览器或网站限制了 Worker，网站原有计时器继续运行。
- **曾停顿 N 秒**：观察到计时回调出现较长间隔，建议检查平台记录的学习进度。

状态提示可能在全屏播放器中不可见，可以退出全屏后查看。

## 适用范围与原理

- 脚本匹配 `beeline-ai.com` 及其子域名。
- 后台计时兼容仅在 `/student/` 路径启用。
- 计时兼容在页面开始加载时安装；自动跳转在 DOM 就绪后启动。
- 自动跳转定位 `.watch-next-chapter .button-box .right`，并检查按钮文字、可见性和可用状态。
- 后台兼容仅匹配已核对的播放器每秒计时回调，为其增加 Worker 触发来源，并与原生计时器共用执行截止时间，避免重复触发。
- 长时间停顿后不会批量补跑积压回调；网站取消计时器时会同步取消兼容计时。

课程进度仍由网站原有逻辑上报。脚本使用 `@grant none`，没有第三方脚本依赖，运行时不请求本仓库或额外的进度上报接口。Tampermonkey 可通过脚本元数据中的更新地址检查仓库版本。

## 常见问题

### 安装后没有任何提示

确认脚本和 Tampermonkey 均已启用，检查“允许用户脚本”设置，然后刷新课程播放页。若播放器处于全屏，请先退出全屏查看。

### 视频开始后一直显示“等待视频播放”

先刷新页面，再重新播放。后台计时需要在播放器创建计时器之前安装；若仍未接管，可能是播放器代码发生了变化，或脚本没有运行在页面主环境中。

### 仍提示“学习进度同步延迟，请刷新页面后继续学习”

该提示涉及网站自身的进度同步。请按平台提示处理并核对学习进度；Worker 本身也可能受后台限制，不能保证解决所有情况。浏览器的休眠或节能设置、网络连接和登录状态也需要分别排查。

脚本保留网站的异常提示，便于及时发现同步问题。

### 怎样反馈问题

在 [Issues](https://github.com/ThunderGodTG/beeline-course-helper/issues) 中说明浏览器版本、脚本版本、左右两侧状态提示，以及复现步骤。截图和链接请遮住姓名、账号、令牌及其他个人信息。

## 验证情况

合并版已通过 JavaScript 语法检查，并使用网站原有的计时回调在本地 Edge 模拟页面中检查了以下行为：

- 页面初始加载时先安装计时兼容，再初始化自动跳转。
- 完整的 30 秒计时周期，以及模拟原生计时器停止触发时的 Worker 计时。
- 原生和 Worker 同时触发时避免重复计数。
- 暂停、恢复，以及两种计时器清除方法的取消行为。
- Worker 被内容安全策略限制时保留原生计时。
- 结束弹窗识别、防重复点击、复用弹窗再次触发，以及自动跳转开关。

模拟测试不包含平台服务端的进度验收，也不能覆盖所有浏览器真实后台和冻结场景。

如需自行做语法检查，可在安装 Node.js 后执行：

```sh
node --check beeline-course-helper.user.js
```
